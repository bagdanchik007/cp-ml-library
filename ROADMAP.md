# Roadmap

Diese Roadmap beschreibt die geplante Entwicklung der Cpp ML Library.

Die Reihenfolge und Inhalte können sich im Laufe der Entwicklung ändern.

## Aktueller Stand

Die Library enthält bereits:

* Matrix und lineare Algebra
* Regression
* Klassifikation
* Clustering
* Preprocessing
* Feature Selection
* Model Selection
* Cross Validation
* Grid Search
* Evaluation Metrics
* Pipelines
* Dataset-Unterstützung

## Version 1.2

## Langfristige Ziele

Langfristig soll die Cpp ML Library:

* Eine verständliche Machine-Learning-Library für C++ sein.
* Moderne C++-Techniken verwenden.
* Möglichst wenige externe Abhängigkeiten besitzen.
* Gut testbar und dokumentiert sein.
* Für Lernen, Experimente und Portfolio-Projekte geeignet sein.

## Hinweise

Diese Roadmap stellt keine Garantie dar. Features können hinzugefügt, verschoben oder entfernt werden.
